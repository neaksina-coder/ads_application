How Neak Sina Ads Manager Uses the Google Ads API

Transparent disclosure of all Google Ads API usage

Overview

Neak Sina Ads Manager uses the Google Ads API (v24) to perform advertising account management operations on behalf of authorized users. The platform accesses only Google Ads accounts where the account owner or an authorized user has explicitly granted access through Google OAuth 2.0.

API Operations Used

The platform uses the following Google Ads API services:

  • GoogleAdsService.SearchStream — fetch campaign, ad group, ad, asset, and reporting data
  • googleAds:mutate — create or update campaign budgets, campaigns, ad groups, ads, and assets
  • Customer listing — list accessible Google Ads customer accounts

What We Do NOT Do

  • We do not create new Google Ads accounts
  • We do not use keyword planning services
  • We do not expose the developer token in the browser
  • We do not access accounts without OAuth authorization
  • We do not sell or share Google Ads data with third parties

Token and Credential Handling

  • Developer token: stored in backend environment variables only
  • OAuth refresh tokens: encrypted at rest, server-side only
  • Access tokens: short-lived, never sent to the browser
  • No Google credentials are stored in browser code or cookies

Campaign Creation Safety

  • All campaigns are created as PAUSED by default
  • Backend sends validate-only requests before production mutations
  • Users must confirm before any campaign is created or enabled
  • Every API mutation is logged with user ID and timestamp
