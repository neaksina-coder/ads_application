How Neak Sina Ads Manager Uses the Google Ads API

Full transparency disclosure of all Google Ads API usage

Overview

Neak Sina Ads Manager uses the Google Ads API (v24) to perform advertising account management operations on behalf of authorized users. The platform accesses only Google Ads accounts where the account owner or an authorized user has explicitly granted access through Google OAuth 2.0. No accounts are accessed without explicit authorization.

API Services Used

The platform uses the following Google Ads API services:

  • GoogleAdsService.SearchStream - fetch campaign, ad group, ad, asset, and reporting data
  • googleAds:mutate - create or update campaign budgets, campaigns, ad groups, ads, and assets
  • Customer listing - list accessible Google Ads customer accounts after OAuth authorization

Supported Campaign Types

Search, Display, Demand Gen, Performance Max

What We Do NOT Do

  • We do not create new Google Ads accounts
  • We do not use keyword planning services
  • We do not use App Conversion Tracking and Remarketing API
  • We do not expose the developer token in the browser
  • We do not access accounts without OAuth authorization
  • We do not sell or share Google Ads data with third parties
  • We do not use a token developed by someone else

Token and Credential Handling

  • Developer token: stored in backend environment variables only, never in browser code or API responses
  • OAuth refresh tokens: encrypted with AES-256 at rest, server-side only
  • Access tokens: short-lived, held in server memory, never sent to browser
  • No Google credentials stored in cookies, localStorage, or frontend code

Campaign Creation Safety

  • All campaigns created as PAUSED by default
  • Backend sends validateOnly: true requests before production mutations
  • Users must explicitly confirm before any campaign is created or enabled
  • Every API mutation logged with user ID, account ID, and timestamp
